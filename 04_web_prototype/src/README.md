# Prototype code boundary

前端原型（对齐 `01_requirements/Komodo_Hub_SRS_CN.md`）：五端登录、本地 `localStorage`（键 `komodo_hub_v1_3`）。

## 演示账号

见项目根目录 [`README.md`](../README.md) 中的 **「演示账号与密码」** 与 **班级邀请码** 表。

## 班级邀请码（功能说明）

- 教师：**班级管理** 查看/复制/重新生成邀请码。
- 学生：**注册**时必填邀请码；已注册但未入班的学生在首页/任务/通讯/报告页可再次输入验证码加入。
- 未入班学生无法提交作业、观察报告与师生留言。

## 文件

| 文件 | 职责 |
|---|---|
| `store.js` | 数据、警告/禁言、迁移 |
| `auth.js` | 登录注册、各角色导航 |
| `views.js` | 各端页面 |
| `app.js` | 认证分页、事件 |
| `styles.css` | 样式 |

## SRS 对照要点

| 需求 | 原型 |
|---|---|
| 登录 + 独立注册页 | 登录页「注册账号」 |
| 访客 | 物种库、公开活动、社区（只读） |
| 学生资料/作业得分 | 个人主页、学习任务 |
| 教师报告评分 | `学生报告评分` |
| 管理内容审查 | 不发帖；审查/删帖/警告 |
| 公众加入社区、举报 | `加入社区`、举报→社区负责人 |
| 社区帖子审核 | `帖子审核`、删帖、禁言 |
